# 🎀 Birthday Surprise

Төрсөн өдрийн мэндчилгээний хөөрхөн интерактив вэбсайт.
Ягаан цэгэн дэвсгэр, тууз, улаан бантан, гүзээлзгэнэтэй бялуутай coquette загвар.

**Урсгал нь**

1. **Нүүр хуудас** дээр "Happy Birthday" гарчиг болон бэлэг харагдана. Бэлэг дээр дарахад таг нь нээгдэж, конфетти цацагдаад хөгжим эхэлнэ.
2. **"Click one to proceed!"** гэсэн 4 цонх гарч ирнэ. Үзсэн цонхны буланд зүрх тэмдэг гарна.
   - 📷 **Memories** нь polaroid зургуудын хана
   - 🎵 **Our songs** нь эргэдэг пянзтай хөгжим тоглуулагч
   - 💐 **For you** нь цэцгийн баглаа, дотор нь захидал
   - 🎂 **Make a wish** нь лааг нь үлээдэг бялуу
3. Дөрвүүлэнг нь үзээд буцаж ирэхэд дахиад конфетти бууна.

## ✏️ Алхам 1. Өөрийнхөөрөө болгох

Бүх зүйлийг `js/config.js` файлаас өөрчилнө.

**Нэр солих**
```js
name: "Baby",
```

**Зураг нэмэх**
1. Зургаа `assets/photos/` хавтас руу хуулна (жишээ нь `1.jpg`, `2.jpg`)
2. `config.js` дотор ингэж бичнэ
```js
photos: [
  { src: "assets/photos/1.jpg", caption: "the day we met" },
  { src: "assets/photos/2.jpg", caption: "our first trip" },
],
```
> 💡 Зургийн нэрэнд зай, монгол үсэг бүү хэрэглээрэй. `1.jpg`, `trip.jpg` гэх мэт энгийн нэр тохиромжтой.
> 💡 Утсаар авсан том зургийг жижигрүүлбэл хурдан ачаалагдана (1200px орчим хангалттай).

**Дуу нэмэх**
1. mp3 файлаа `assets/music/` руу хуулна
2. `config.js` дотор бичнэ
```js
songs: [
  { title: "Best Part", artist: "Daniel Caesar ft. H.E.R.", src: "assets/music/best-part.mp3", cover: "assets/photos/1.jpg" },
  { title: "Happy Birthday", artist: "a little music box, for you", src: "" },
],
```
`src` хоосон байвал хөгжмийн хайрцагны "Happy Birthday" ая тоглоно.

Бэлэг нээх үед аль дуу эхлэхийг `startSong` сонгоно. Жагсаалтын эхний дуу бол `0`, хоёр дахь нь `1`.
```js
startSong: 0,
```

> 💡 iPhone-оор авсан зураг ихэвчлэн `.HEIC` байдаг. Браузер үүнийг харуулж чаддаггүй тул `.jpg` болгож хөрвүүлээрэй. iPhone дээр Settings → Camera → Formats → **Most Compatible** болгосноор дараагийн зургууд шууд jpg болно.

**Захидал бичих**
```js
letter: {
  greeting: "My love,",
  paragraphs: [
    "Эхний догол мөр…",
    "Хоёр дахь догол мөр…"
  ],
  signature: "forever yours ♡"
},
```

## 🚀 Алхам 3. GitHub дээр тавьж, линк үүсгэх

### 3.1 GitHub дээр repo үүсгэх
1. https://github.com/new руу орно
2. **Repository name** хэсэгт `happy-birthday` гэх мэт нэр өгнө
3. **Public** сонгоно (GitHub Pages үнэгүй ажиллахын тулд)
4. **Create repository** дарна

### 3.2 Кодоо push хийх
Terminal дээр энэ хавтас дотроос

```bash
git init
git add .
git commit -m "Birthday surprise 🎀"
git branch -M main
git remote add origin https://github.com/ТАНЫ-НЭР/happy-birthday.git
git push -u origin main
```

### 3.3 GitHub Pages асаах
1. Repo-гийнхоо **Settings** руу орно
2. Зүүн талын цэснээс **Pages** сонгоно
3. **Source** хэсэгт **Deploy from a branch** сонгоно
4. **Branch** хэсэгт `main` болон `/ (root)` сонгоод **Save** дарна
5. 1-2 минут хүлээгээд хуудсаа refresh хийхэд линк гарч ирнэ

Линк нь иймэрхүү харагдана
```
https://ТАНЫ-НЭР.github.io/happy-birthday/
```

Энэ линкийг төрсөн өдөр нь болж буй хүндээ илгээгээрэй 💌

### 3.4 Дараа нь өөрчлөлт оруулах
```bash
git add .
git commit -m "add photos"
git push
```
Push хийснээс хойш 1 минутын дотор сайт шинэчлэгдэнэ.

## ⚠️ Анхаарах зүйлс

- **Repo нь Public** байгаа тул зургууд нь линк мэддэг хэнд ч харагдана. Хэтэрхий хувийн зураг оруулахгүй байхыг зөвлөе.
- **Дууны зохиогчийн эрх.** Хувийн бэлэг болгож хэрэглэх нь түгээмэл ч, алдартай дууны mp3-г public repo-д тавих нь зохиогчийн эрхийн асуудал үүсгэж болзошгүй. Хөгжмийн хайрцагны ая нь чөлөөтэй хэрэглэж болох ая.
- **Дуу автоматаар эхлэхгүй.** Браузерууд хэрэглэгч дарахаас өмнө дуу тоглуулахыг хориглодог. Тиймээс бэлэг дээр дарахад л хөгжим эхэлдэг.

## 🎨 Өнгө солих

`css/style.css` файлын эхэнд байгаа өнгөнүүдийг сольж болно.

```css
--cream:#fdf6ee;   /* шатрын цайвар нүд */
--rose:#efc3cb;    /* шатрын ягаан нүд */
--ink:#a24f66;     /* зурааны шугамын өнгө */
--ink-deep:#6f2c41;/* гарчиг, текст */
```

Жишээ нь видео шиг цэнхэр болгох бол `--rose:#c5d8ee`, `--ink:#3f5f99`, `--ink-deep:#24396b` гэж солиорой.
